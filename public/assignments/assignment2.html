Before you begin

Green fluorescent protein (GFP) emits green light and is widely used to visualize gene expression, protein localization, and cellular processes. Mutations can change its brightness, folding, and other properties. In this assignment, you will design GFP variants by simulating directed evolution: generate candidates, evaluate them, and select promising sequences.

All students will implement a genetic algorithm, in which a population evolves through selection, crossover, and mutation. Graduate students will also implement Markov chain Monte Carlo (MCMC) and evaluate their final designs with a pretrained structure model.

Dataset: GFP sequences and brightness

We will use the GFP measurements from Sarkisyan et al. (2016). The data and reference sequence are available on Figshare. In the experiment, the researchers made many GFP variants and measured how brightly they fluoresced.

The file amino_acid_genotypes_to_brightness.tsv groups measurements by amino acid genotype. A barcode is a short DNA identifier used to track a GFP variant; several barcodes can represent the same amino acid sequence.

ColumnMeaning
aaMutationsSubstitutions relative to the reference; empty for wild type.
uniqueBarcodesNumber of barcodes representing the genotype.
medianBrightnessMedian log-brightness across these barcodes.
stdStandard deviation of log-brightness; empty when there is only one barcode.

Reading the mutation notation

Positions in aaMutations are zero-based amino acid indices, just like Python string indices. For example, SA108D means “replace alanine (A) at index 108 with aspartate (D).” The first letter, S, denotes a substitution. A colon separates mutations, so SA108D:SN144D describes a sequence with two changes relative to the reference.

A simple fitness oracle

A genetic algorithm needs a score for each candidate it creates. Some candidates will be new combinations of mutations, so we cannot simply look up their brightness in the data. We will use a function called a fitness oracle to estimate their brightness.

In research, this function might be a deep neural network trained to predict a protein property, or a structure-based calculation with software such as Rosetta. For this exercise, we will use a much simpler rule: add the measured effects of individual substitutions.

Suppose the reference has log-brightness FWT, and a sequence with just one substitution at position j has measured log-brightness Fj,a. We estimate the effect of that substitution as Δj,a = Fj,a − FWT. For a candidate with several substitutions, our estimate is:

F̂(s) = FWT + ∑j : sj ≠ WTj Δj,sj.

For example, if two substitutions individually change log-brightness by −0.2 and +0.1, we predict a total change of −0.1 when they occur together. This assumes their effects add. It does not capture interactions between substitutions, called epistasis.

Some possible single substitutions were not measured. For these, we use the median measured single-substitution effect at that position. If the position has no single-substitution measurements, we use the median effect across all measured single substitutions.

Finally, we cap predictions at the smallest and largest log-brightness values in the dataset. This keeps the sum from producing implausibly large or small values. These rules define a simple teaching model built from the experimental measurements. The data are already logarithmic, so we do not take another logarithm.

The complete oracle is provided below. Run it before starting the exercises. You do not need to modify this code. You can use it directly to calculate fitness.

# Effects measured in genotypes with exactly one substitution.
single_effects = {
    muts[0]: F[i] - F_WT
    for i, muts in enumerate(mutations) if len(muts) == 1
}
global_default = float(np.median(list(single_effects.values())))
site_defaults = {}
for j in range(L):
    observed = [effect for (position, new), effect in single_effects.items()
                if position == j]
    site_defaults[j] = (float(np.median(observed)) if observed
                        else global_default)
F_min, F_max = float(F.min()), float(F.max())

def oracle(sequence):
    """Estimate log-brightness by adding single-substitution effects."""
    if len(sequence) != L or any(a not in AA for a in sequence):
        raise ValueError("Use a full-length amino acid sequence.")
    predicted = F_WT
    for j, amino_acid in enumerate(sequence):
        if amino_acid != WT[j]:
            predicted += single_effects.get((j, amino_acid), site_defaults[j])
    return float(np.clip(predicted, F_min, F_max))

# Start from WT and 39 measured sequences with 1-3 substitutions.
starting_pool = np.array([i for i, muts in enumerate(mutations)
                         if 1 <= len(muts) <= 3])
def starting_population(seed):
    rng = np.random.default_rng(seed)
    chosen = rng.choice(starting_pool, 39, replace=False)
    population = [WT] + [sequences[i] for i in chosen]
    measured = np.array([F_WT] + [F[i] for i in chosen])
    return population, measured, rng

initial_population, starting_measured_F, rng = starting_population(0)
print("Measured WT log-brightness:", F_WT)
print("Oracle WT log-brightness:", oracle(WT))
